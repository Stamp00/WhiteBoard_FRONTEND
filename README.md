# Whiteboard – frontend

Statiska filer, ingen build behövs. Ställ in API-adresserna i `config.js` och servera mappen med valfri
webbserver, t.ex. `npx serve -l 8080 .`, eller ladda upp den till people.arcada.fi.
Valfritt: `docker build -t whiteboard-frontend . && docker run -p 8080:8080 whiteboard-frontend`.
